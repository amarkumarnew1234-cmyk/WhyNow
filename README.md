# WhyNow

**An Intent-Activity Alignment and Digital Behaviour Awareness System**

## Overview

WhyNow is a digital behaviour awareness system that records a user's intended purpose for starting a session and the activities performed during that session.

The system is designed to compare intention with recorded activity, identify possible intent drift, distinguish contextual or intentional changes, and provide non-judgmental awareness of digital behaviour.
